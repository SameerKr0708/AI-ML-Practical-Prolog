Prolog Practicals: Introduction to AI & ML

Lab experiments (Unit 1 and Unit 2) for the Introduction to Artificial Intelligence & Machine Learning course, written in SWI-Prolog.

Unit 1: Introduction to AI and Intelligent Agents
- Knowledge base (student-course database)
- Arithmetic, factorial and Fibonacci using recursion
- List operations (append, reverse, member, length)
- College timetable database
- Student performance analysis using rules
- Travel route recommendation system

Unit 2: Problem Solving and Searching
- Breadth-First Search (BFS)
- Depth-First Search (DFS)
- Hill Climbing optimization
- Blocks World
- Rule-based expert system for fault diagnosis
- Water Jug problem (state-space search)
- Tic-Tac-Toe agent using Minimax

How to run
Install [SWI-Prolog](https://www.swi-prolog.org), then run:

    swipl -s exp01_knowledge_base.pl
